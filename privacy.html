Privacy Policy

Last updated: 6 November 2026

Channel Growth is a personal tool used only by its owner, Himanshu Chauhan, to read analytics for his own YouTube channel and Instagram account.

What data it accesses

  • Read-only YouTube Data API and YouTube Analytics API data for the owner's own channel: video list, views, watch time, retention, subscribers and similar statistics.
  • Read-only Instagram insights for the owner's own professional account, if connected.

How data is used and stored

  • Data is used only to help the owner understand and improve his own content.
  • Data is stored only on the owner's personal computer. Access tokens are kept in the operating system's credential store.
  • Data is never sold, shared with third parties, or used for advertising.
  • The tool never uploads, publishes, deletes or changes anything on YouTube or Instagram.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is accessed through YouTube API Services, subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from Google account permissions. Stored data can be deleted by removing the tool's local data folder and its saved credentials.
